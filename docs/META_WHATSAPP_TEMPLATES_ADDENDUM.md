# Meta WhatsApp Business Templates — v3.4.3 Addendum

Create these two templates in Meta Business Manager (WhatsApp > Message Templates), category **UTILITY**, language **en**.

## 1. `medical_certificate_ready`
- **Header (text):** Medical Certificate Ready
- **Body:**
```
Hello {{1}},

Your medical certificate has been generated by {{2}}.

Certificate Type: {{3}}
Issue Date: {{4}}

You can access the certificate using the link below:
{{5}}

For assistance, contact: {{6}}

Regards,
NeoKidsPro
```
- **Variables:** {{1}} Patient Name · {{2}} Doctor Name · {{3}} Certificate Type · {{4}} Certificate Date · {{5}} Secure Certificate URL · {{6}} Clinic Name
- **Buttons:** 1 × URL button — text `View Certificate`, URL suffix `{{5}}` (dynamic URL; register base URL as your domain, e.g. `https://app.neokidspro.com/api/files/share-record/` with `{{1}}` as the button variable if Meta requires a static base — then map button {{1}} = token portion).

## 2. `historical_record_shared`
- **Header (text):** Medical Record Shared
- **Body:**
```
Hello {{1}},

{{2}} has shared a medical record for your reference.

Record Type: {{3}}
Record Date: {{4}}

You can access the document using the secure link below:
{{5}}

For assistance, contact: {{6}}

Regards,
NeoKidsPro
```
- **Variables:** {{1}} Patient Name · {{2}} Doctor Name · {{3}} Record Type · {{4}} Record Date · {{5}} Secure Record URL · {{6}} Clinic Name
- **Buttons:** 1 × URL button — text `View Record`, URL `{{5}}`.

### Notes
- Until templates are approved, the backend falls back to a plain-text session message (valid inside the 24h window) so sharing never hard-fails.
- Links are HMAC-signed and expire after 7 days (`HISTORICAL_SHARE_TTL_SEC`).
- Meta rejects URLs with paths in *body* samples sometimes — if so, move the URL to the button only and remove `{{5}}` from the body.
